# sudokupad-scripts

Tampermonkey userscripts for [SudokuPad](https://sudokupad.app).

## Install

Install [Tampermonkey](https://www.tampermonkey.net/), then open a script's link below. Tampermonkey offers to install it.

- [Color by Digit](https://raw.githubusercontent.com/caneff/sudokupad-scripts/main/color-by-digit.user.js): adds a button that colors every cell holding a digit, and every empty cell whose centre marks all belong to one group, using groups of palette colors set in a settings dialog.
- [Digit Color](https://raw.githubusercontent.com/caneff/sudokupad-scripts/main/digit-color.user.js): colors the digits themselves, one color per digit, in entered digits, corner marks and centre marks. Starts from default colors; change them in a settings dialog. Givens keep their color; a conflicting mark keeps its digit color and gets a small red circle behind it.
- [Pen Tool Extras](https://raw.githubusercontent.com/caneff/sudokupad-scripts/main/pen-tool-extras.user.js): three things for the pen tool, in one settings dialog. **Colors:** changes the pen's nine colors. Strokes already drawn and the tool's color buttons change with them. With nothing saved, the nine pen colors are your current cell color page, darkened, each pen on the same button number as its cell color (pen 1 takes the page's color on button 1, and so on; button 0 is not used), with the darkest grey turned black, so installing changes the pen colors straight away; a cell color that is transparent or unreadable leaves SudokuPad's own pen color on that button; edit and Save to keep your own. Holding a pen color button for a second (with either mouse button) puts a color picker over each button, as the cell color tool does: click one to open the picker, and the pen changes live and the set is saved; hold again, or leave the pen tool, to close them. The colors are read when the page loads, so changing cell colors later does not move the pen until the next load. **Thickness:** one slider (1 to 12; SudokuPad's own pen line is 5) scales pen lines, the pen's cell circles and crosses, and the edge marks together: at 5 everything draws at its usual width, and moving the slider changes each by the same factor. It previews live, Cancel undoes it, and saving a thickness does not turn the colors into a saved set. **Edge marks:** adds direction arrows (`>` `<` on a vertical edge, `^` `v` on a horizontal one) and a circle (a small open ring; a dot saved by an earlier version draws as the circle) to the pen tool's marks on a cell edge. Clicking an edge cycles through the marks ticked in the dialog, each shown with a small picture; the pen tool's own X is one of them. These wrap SudokuPad's pen tool and renderer, which are internals, so a SudokuPad update can break them, and the edge marks are then left off while the colors and thicknesses still work. Restore defaults goes back to the darkened page and the default thickness. Turn the pen tool on in settings first. It replaces Pen Color and Edge Marks: installed copies of those two stop updating, so remove them by hand in Tampermonkey; your saved colors and edge marks carry over.
- [Dark Page](https://raw.githubusercontent.com/caneff/sudokupad-scripts/main/dark-page.user.js): makes the page black around the puzzle, or another color you pick in a settings dialog (a color picker, and a Black button to go back); the choice is kept and applies without a reload, and the page's own text turns dark on a light color. On a dark color the control buttons go dark gray with light purple icons; on a light one they stay as SudokuPad draws them. A rectangle bounding everything the puzzle draws, and the cells you write in, stays as SudokuPad renders it. Not SudokuPad's dark mode.
- [No Tab Letters](https://raw.githubusercontent.com/caneff/sudokupad-scripts/main/no-tab-letters.user.js): stops Tab from toggling SudokuPad's letter mode. SudokuPad binds both `/` and Tab to the letter toggle and saves the mode, so a stray Tab left the number pad on letters after a refresh. This replaces only the Tab binding's handler in the letter tool with one that does nothing, so during play Tab does what it did before minus the toggle (focus stays where it is), the letter button and `/` still toggle, and Tab still moves focus in dialogs. It works whenever you turn the letter tool on in settings. It has no settings entry or dialog. If a SudokuPad update changes what it hooks (the letter tool or its Tab binding to the toggle), it logs a warning in the browser console and changes nothing.

Each script except No Tab Letters adds an entry to SudokuPad's settings, under the Experimental group (collapsed until you open it). The entry shows the script's name; its dialog shows the version in small text beside the heading, so you can tell which one is installed.
