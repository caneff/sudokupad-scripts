Text Annotation

This script can break at any time. It relies on SudokuPad's internals, which any update can change, and it isn't made or supported by SudokuPad.

Adds to SudokuPad a Text Annotation tool for typed notes on the board or beside it, such as cage sums, in colors of its own.

Install Text Annotation

Left click to type a note

One size slider

Background: a box behind the next note

Your own colors: hold a color button

Move: drag a note, on or off the grid

Select: drag a box round notes, then change them together

Long notes wrap and scroll; drag the corner to resize

Erase: right-click a note

The note is gone

What it adds

  • Typed notes

    Click the board to type, such as a cage sum, or anywhere beside it that is not one of SudokuPad's controls. Enter starts a new line. Escape or a click elsewhere finishes the note, and a double-click on a note changes it. While a note is open, the color buttons and the size slider change that note, and it stays open.

  • Long notes

    A long line wraps, and a note stops growing at 8 lines and scrolls: turn the wheel over it, and a thin scroll bar shows while the pointer is on it. While you type, drag the handle on the note's bottom right corner to make its box wider, narrower, taller or shorter; the note keeps that size.

  • Bold, italic and strikethrough

    Write **bold**, *italic* (or _italic_) and ~~strikethrough~~ in a note, and nest them, such as **bold *and italic***. The markers show while you type and are hidden once the note is finished; a marker with no partner shows as typed.

  • Readable over digits

    Each note has a halo, a thin outline of its letters in the page color, so it reads over digits, pencil marks and colored cells.

  • Colors of its own

    Nine colors that belong to Text Annotation, not to SudokuPad's pen. Pick one with a click or the digit keys 1 to 9.

  • Text size

    One slider, from small to large. A note keeps the size it was typed with until you select it and move the slider.

  • Background

    Turn it on and the next note gets a page-colored box behind it, so it reads over the digits. Turning it on or off never changes the notes already there, except one you are editing or the ones selected.

  • Select

    Click a note to select it, Shift+click to add or remove one, or drag a box round several from empty space. The colors, the size slider and Background then change the selected notes, and Escape or a click on empty space ends the selection.

  • Move

    Drag a note to move it, on the board or off it. Drag one of the selected notes and they all move.

  • Erasing

    Right-click a note to erase it. Delete or Backspace, or the trash button in the panel, deletes the selected notes; with none selected the trash button erases every note.

  • Settings

    Color presets, a color picker for each of the nine colors, and Copy and Paste to move them to another browser.

  • Stays on the cells

    A note on the board stays on its cells when the board resizes, and one beside it stays where you put it on the screen, unless the window or the controls would cover it or push it past the window's edge, when it moves to the nearest free spot and stays there. Both stay visible when you switch back to entering digits.

  • Kept for each puzzle

    A reload keeps the notes, for the last 50 puzzles you made notes on.

The Text Annotation panel

Pick the Text tool among SudokuPad's tool buttons and its panel opens beside the puzzle. It holds every control.

Good to know

  • The notes are kept in this browser only, so another browser or device does not show them.
  • Restart clears the notes. If the notes cannot be saved, a message says so.
