Pen Tool Extras

A userscript that adds colors, extra pens, two sliders and edge and corner marks to SudokuPad's pen tool. Turn the pen tool on in SudokuPad's settings first.

Install Pen Tool Extras

Others can't see lines from pens past the first page unless they have the script too. SudokuPad stores those lines and shares them in the replay, but without this script it draws them with no color, so a viewer without it sees the marks missing.

Pen colors

The pen's nine colors match your cell colors, a little darker, so installing changes them straight away. Change them in the settings dialog, or hold a pen color button for a second to put a color picker over each button. Strokes already drawn change with them. Recoloring a pen changes it on every page.

Pen pages

Three pages of nine pens, 27 in all. A page button at the right end of the pen panel's last row shows what the next page draws. Click it, press Tab, or turn the mouse wheel over the pen buttons to change page. The same pen number stays selected, so Tab turns a green line into a dotted green one, and the pen you chose is still there after a reload.

  • Page 1 is SudokuPad's own solid pens.
  • Page 2 draws the same colors as dotted lines. The dialog's dash length slider turns the dots into dashes.
  • Page 3 draws a thin line with a run of chevrons pointing the way you dragged.

Only lines change with the page: a cell circle, a cross and the edge and corner marks stay solid.

Panel sliders and settings

Two sliders sit in the pen tool's panel, so you can change them during play:

  • Thickness scales pen lines, the pen's cell circles and crosses, and the edge and corner marks together.
  • Opacity sets how see-through every pen mark is, so dense marks stop hiding the digits and overlapping lines no longer darken.

A move changes the marks live and is saved at once. The settings dialog holds both sliders too, a dash length slider for page 2, a checkbox to hide each panel slider, and the pen line mode (SudokuPad's pulldown, moved into the dialog). The dialog's Restore defaults goes back to the defaults, and waits for Save.

Edge and corner marks

Click a cell edge with the pen to cycle an X, direction arrows and a circle. Click near a grid corner to cycle an X and a circle. Each mark is a checkbox in the dialog, so you choose which ones the click cycles through.

Right click goes backwards

A right click on an edge or a grid corner steps the same cycle backwards, and keeps the browser's menu closed there. A right click anywhere else keeps its menu. Touch has no right click, so it only steps forward.

Good to know

  • It leans on SudokuPad internals, so an update can break it.
  • It replaces Pen Color and Edge Marks, which you remove by hand in Tampermonkey. Your saved colors and edge marks carry over.
