SudokuPad scripts

These scripts can break at any time, and there are no guarantees. They rely on SudokuPad's internals, which aren't a public API, so any SudokuPad update can break them without notice. They aren't made or supported by SudokuPad.

A few small userscripts for SudokuPad. Install Tampermonkey, click a script's install link, and Tampermonkey asks if you want it.

Color by Digit

Colors cells, or the digits and marks in them, by digit, from groups of colors you set, and keeps the colors in step as you solve. Details

Install Color by Digit

Pen Tool Extras

Makes SudokuPad's pen tool more useful: customizable pen colors, dashed lines and lines with arrows, and marks you can put on cell edges and grid corners. Details

Install Pen Tool Extras

Dark Page

Turns the page black around the puzzle, or any color you pick, and darkens the control buttons when the color is dark. Puzzle colors stay as intended, unlike SudokuPad's dark mode.

Install Dark Page

Auto Rules Resizer

Fits the rules to your screen in landscape: the text grows as large as fits, and the pane widens only as far as long rules need. The f+ and f- buttons and the drag corners show when the pointer is over the pane.

Thanks to Nell Gwynn, whose resizing scripts this grew from.

Install Auto Rules Resizer

Draw Tool

Adds a Draw tool for freehand lines and typed text, such as cage sums, in the pen colors. Each puzzle keeps its own drawing. Details

Install Draw Tool

No Tab Letters

Stops a stray Tab from switching SudokuPad's number pad to letters. The letter button and the / key still switch it.

Install No Tab Letters
