SudokuPad scripts

Tampermonkey userscripts for SudokuPad. Install Tampermonkey, then open a script's install link; Tampermonkey offers to install it.

Color by Digit

Adds a button that colors every cell holding a digit, using groups of palette colors you set in a settings dialog.

Install Color by Digit

Digit Color

Colors the digits themselves, one color per digit, in entered digits, corner marks and centre marks. A conflicting mark gets a small red circle behind it.

Install Digit Color

Pen Color

Sets the pen tool's nine colors to your current cell color page, darkened, until you save your own in a settings dialog. Turn the pen tool on in settings first.

Install Pen Color

Edge Marks

Adds direction arrows and a dot to the pen tool's marks on a cell edge. Relies on SudokuPad internals, so an update can break it. Turn the pen tool on in settings first.

Install Edge Marks

Dark Page

Makes the page black around the puzzle. A rectangle bounding everything the puzzle draws, and the cells you write in, stays as SudokuPad renders it. Not SudokuPad's dark mode.

Install Dark Page
