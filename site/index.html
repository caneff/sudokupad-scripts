Puzzle Scripts

Small userscripts for SudokuPad and for other puzzle sites. Install Tampermonkey, click a script's Install button, and Tampermonkey asks if you want it.

These scripts can break at any time, and there are no guarantees. They rely on SudokuPad's internals, which aren't a public API, so any SudokuPad update can break them without notice. They aren't made or supported by SudokuPad.

Dark Page

Turns the page black around the puzzle, or any color you pick, and darkens the control buttons, the Pen Tool Extras and Text Anywhere panels and the dim behind a dialog when the color is dark. The text under the puzzle stays readable on any color. Puzzle colors stay as intended, unlike SudokuPad's dark mode. Restore defaults in its settings dialog goes back to black.

Install Dark Page

Auto Rules Resizer

Fits the rules pane to your screen: it takes the spare height, widens for long rules, and grows or shrinks the text to fit. A size you set with f+, f- or the drag corners is kept per puzzle. Thanks to Nell Gwyn, whose SudokuPad-ResizeRules this grew from.

UI Tweaks

Small changes to SudokuPad's buttons, each switched on or off in a settings dialog that opens from SudokuPad's settings. Restore defaults there puts the choices back to how they start.

  • Tab never switches to letters (on at first): a stray Tab no longer switches the number pad to letters. The letter button and the / key still do.
  • Hide the Select button (off at first): takes the button out of the bottom row, and the other buttons close up.
  • Wrap buttons (off at first): the bottom row of tool buttons wraps onto a second line after five. It has no effect with Color by Digit installed, which already wraps it.
  • Digit pad size (Normal at first): Smaller, Normal, Larger or Largest digit buttons. SudokuPad fits the whole controls column to the window, so the digits grow most on a large screen, and on a laptop the other buttons shrink to make room.
