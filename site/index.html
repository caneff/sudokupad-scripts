Dark Page

Turns the page black around the puzzle, or any color you pick, and darkens the control buttons when the color is dark. The text under the puzzle stays readable on any color. Puzzle colors stay as intended, unlike SudokuPad's dark mode.

Install Dark Page

Auto Rules Resizer

Fits the rules to your screen in landscape: the pane takes all the height the page has to spare, widens only as far as long rules need, and only then does the text shrink, to 70% of SudokuPad's size at the least. Short rules get larger text, up to 150%. A puzzle's text size and pane size, if you change them with f+, f- or the drag corners, are kept per puzzle: you get them back when you return to it, and every other puzzle starts at the fitted default. Restore defaults in the Auto Rules Resizer settings clears the current puzzle's. Thanks to Nell Gwynn, whose resizing scripts this grew from.

Install Auto Rules Resizer

UI Tweaks

Small changes to SudokuPad's buttons, each switched on or off in a settings dialog that opens from SudokuPad's settings.

  • Tab never switches to letters (on at first): a stray Tab no longer switches the number pad to letters. The letter button and the / key still do.
  • Hide the Toggle Selection button (off at first): takes the button out of the bottom row, and the other buttons close up.
  • Wrap buttons (off at first): the bottom row of tool buttons wraps onto a second line after five.
