SudokuPad scripts

These scripts can break at any time, and there are no guarantees. They rely on SudokuPad's internals, which aren't a public API, so any SudokuPad update can break them without notice. They aren't made or supported by SudokuPad.

Small userscripts for SudokuPad. Install Tampermonkey, click a script's Install button, and Tampermonkey asks if you want it.

Color by Digit

Colors cells, or the digits and marks in them, by digit, with colors you give to groups of digits, and keeps the colors in step as you solve.

Pen Tool Extras

Makes SudokuPad's pen tool more useful: customizable pen colors, dashed lines and lines with arrows, and marks you can put on cell edges and grid corners.

Draw Tool

Adds a Draw tool for freehand lines, shapes and typed text, such as cage sums, in colors of its own. Each puzzle keeps its own drawing.

Dark Page

Turns the page black around the puzzle, or any color you pick, and darkens the control buttons when the color is dark. Puzzle colors stay as intended, unlike SudokuPad's dark mode.

Install Dark Page

Auto Rules Resizer

Fits the rules to your screen in landscape: the text grows as large as fits, and the pane widens only as far as long rules need. Thanks to Nell Gwynn, whose resizing scripts this grew from.
