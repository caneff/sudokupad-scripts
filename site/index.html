SudokuPad scripts

A few small userscripts for SudokuPad. Install Tampermonkey, click a script's install link, and Tampermonkey asks if you want it.

Color by Digit

A button that colors cells by their digit, in groups you set in a dialog. Empty cells whose centre marks all fall in one group get colored too.

Install Color by Digit

Digit Color

Gives each digit its own color, in entered digits and in corner and centre marks. A mark that conflicts gets a small red circle behind it.

Install Digit Color

Pen Tool Extras

Makes the pen's nine colors match your cell colors, a little darker, and sets how thick its lines and edge marks are with one slider. Click a cell edge with the pen to cycle an X, two arrows and a circle; right click goes back. It leans on SudokuPad internals, so an update can break it. Turn the pen tool on in SudokuPad's settings first. It replaces Pen Color and Edge Marks, which you remove by hand.

Install Pen Tool Extras

Dark Page

Turns the page black around the puzzle, or any color you pick, and darkens the control buttons when the color is dark. The puzzle and the cells you write in stay as SudokuPad draws them. It is not SudokuPad's dark mode.

Install Dark Page

No Tab Letters

Stops a stray Tab from switching SudokuPad's number pad to letters, which it then remembers after a refresh. During play Tab does nothing, as before; the letter button and the / key still work, and Tab still moves focus in dialogs. Turn the letter tool on in SudokuPad's settings first. It has no settings of its own.

Install No Tab Letters
